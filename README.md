# DSA Assignment: Data Structures and File Search

Implementation of **Stack**, **Singly Linked List (SLL)**, and **Doubly Linked List (DLL)** performing:
- Search
- Insertion (First, Any Position, Last)
- Deletion (First, Any Position, Last)

Reads and searches from 3 generated datasets (Sorted, Unsorted with Duplicates, Unsorted Unique).

## Running the Code
```powershell
python dsa_structures.py
```
